## ✦ About Aura Crasher

**Aura Crasher** is a free WhatsApp bug bot project created by **Anuhas**.



## 📦 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/DEVPRIMIS/Squichy-Free.git
cd Squichy-Free
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure the project

Check the project configuration and environment variables before starting the bot.

### 4. Start the bot

```bash
npm start
```

> The exact start command may depend on the `package.json` configuration of your version.
